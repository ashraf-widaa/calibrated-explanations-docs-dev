## 3. Verification rule for any notebook link (Phase 3)

1. Run `PYTHONPATH=src python scripts/docs/run_notebooks.py` (inspect its CLI
   first; do not guess flags) on the candidate notebook.
2. Record CE version, Python version, runtime and pass/fail.
3. Link only passing notebooks; list failing ones in the phase report as
   "needs an upstream fix" (the official repository is read-only).
