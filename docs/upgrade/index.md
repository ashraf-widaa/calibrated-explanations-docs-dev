# Upgrade & migration

<span id="upgrade-guides"></span>

This is the single entry point for moving to a newer CE release.

1. **Find your version** below and follow its checklist, in order, for every
   release you skip.
2. **Check breaking changes and deprecations** in the
   {doc}`migration guides <../migration/index>`.
3. **See what changed** in the
   {doc}`changelog and release references <../appendices/changelog_links>`.

Version-specific checklists for upgrading to newer CE releases. For recommended production
configuration, see the {doc}`safe-defaults guide <../foundations/how-to/safe-defaults>`.
