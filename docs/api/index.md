# API Reference

This section contains the API reference for the public classes and methods of the `calibrated_explanations` package.

**Start here:** almost all code uses
{doc}`WrapCalibratedExplainer <calibrated_explainer>`: wrap a model, `fit`,
`calibrate`, then predict or explain. The {doc}`Quickstart <../get-started/quickstart>`
runs the whole lifecycle with real output, and the
{doc}`Quick API <../get-started/quick_api>` lists the calls by task.
When a call fails, {doc}`exceptions` lists what CE raises and why.
Choose the question in {doc}`../get-started/ce-tasks-and-modes`, then use
this reference for signatures, parameters and return types.

For short definitions of CE objects, methods and parameters, see the {doc}`Software & Technical Glossary <../glossary/software>`.
