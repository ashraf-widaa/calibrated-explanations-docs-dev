# Documentation maintenance

The {doc}`contributor guide <../contributor/index>` describes how to contribute
to CE and its documentation. Documentation changes should preserve accurate
API examples, scientific qualifications, useful references and working links.

The internal audience assignments remain recorded in the project's
[documentation audience standard](https://github.com/Moffran/calibrated_explanations/blob/main/development/standards/STD-004-documentation-audience-standard.md).
They are maintenance metadata, rather than instructions that readers must
follow to understand CE.
